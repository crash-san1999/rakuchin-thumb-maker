## 1. はじめに：3分でサムネを作る

| 手順 | やること |
|---|---|
| ① 背景 | 「＋追加」→「背景画像」で画像を選ぶ。画像を画面にドラッグして「背景にする」に離してもOK |
| ② 文字 | キャンバスの文字をクリックして、左の「テキスト」タブで入力。`{ }` で囲んだ部分は強調色になります |
| ③ スタイル | 「スタイル」タブでプリセットを1つクリック。気に入らなければ「配色シャッフル」 |
| ④ 画像・演出 | キャラ画像は画面にドロップ。集中線などは「＋追加」→「動的エフェクト」 |
| ⑤ 保存 | 右上の「サムネを保存」で PNG／JPG を書き出し |

作業内容はブラウザに自動で保存されるので、タブを閉じても次に開いたときに続きから作れます。

起動時に表示される「かんたん操作ガイド」は、右上の **？** ボタンか `?` キーでいつでも開けます。

![かんたん操作ガイド](img/help.png)

## 2. 画面の見かた

| 場所 | 内容 |
|---|---|
| ヘッダー左 | **サムネ作成／文字素材** の切り替え、**＋追加** |
| ヘッダー右 | ヘルプ、PC／スマホ表示の切り替え、元に戻す／やり直し、書き出しサイズ、JPG／PNG、**ファイル**（フォルダのアイコン）、コピー、保存 |
| 左：設定パネル | **選んでいるものの設定** が出ます（下の表） |
| 中央 | キャンバス（1920×1080 基準）。上にガイド、下に情報バー（視認性・小さく表示） |
| 右：レイヤーパネル | 文字・画像・エフェクトの一覧。上にあるほど手前に表示されます |

### 設定パネルは「選んだもの」に合わせて変わります

キャンバスかレイヤーパネルで何かを選ぶと、左の設定パネルがそのための設定に切り替わります。パネルの上に、何を選んでいるかとタブが出ます。

| 選んでいるもの | タブ |
|---|---|
| 何も選んでいない | **背景**（背景の種類・位置）／**色調**／**効果**（背景エフェクト） |
| 文字 | **テキスト**／**スタイル**（プリセット・配色）／**フォント**／**装飾**／**配置** |
| 画像 | **配置**／**フレーム**（切り抜きフレーム）／**フチ・影** |
| 分割フレーム | **分割**／**マスの画像**／**効果**／**配置** |
| 動的エフェクト | **エフェクト**／**配置** |

- 「配置」タブには、大きさ・回転・不透明度・描画モード・ロック・9か所への整列があります（どのレイヤーでも共通）
- 右上の「選択解除」を押すか、キャンバスの何もないところをクリックすると、背景の設定に戻ります
- タブは種類ごとに最後に開いたものを覚えています

## 3. 追加メニュー

文字・画像・分割フレーム・背景画像・動的エフェクトは、すべて **「＋追加」** から追加します（ヘッダー左と、レイヤーパネルの右上にあります）。

![追加メニュー](img/add-menu.png)

| 項目 | 内容 |
|---|---|
| 文字 | 新しい文字レイヤー |
| 画像 | キャラ・素材などの画像レイヤー（複数まとめて選べます） |
| 分割フレーム | 2〜6枚の画像を並べるレイヤー（→ [9章](#9-分割フレーム複数の画像を並べる)） |
| 背景画像 | サムネ全体の背景にする画像 |
| 動的エフェクト | 集中線・光・キラキラ・爆発（→ [10章](#10-動的エフェクト)） |

画像ファイルは、画面のどこにドラッグ＆ドロップしても画像レイヤーとして追加されます（「背景にする」の枠に落としたときだけ背景になります）。コピーした画像を `Ctrl+V` で貼り付けても追加できます。フォントファイル（.ttf / .otf）やプロジェクト（.json）も、同じようにドロップで読み込めます。

![ドラッグ＆ドロップ](img/dragdrop.png)

## 4. 背景

何も選んでいないとき、左の設定パネルが背景の設定になります（レイヤーパネルの「背景」の行をクリックしても開きます）。

<img src="img/ins-bg-tone.png" width="260" alt="色調タブ">
<img src="img/bg-effects.png" width="260" alt="効果タブ">
</p>

### 背景タブ

- **背景を非表示にする／背景の不透明度**：非表示にして PNG で保存すると、背景が透明な画像になります
- **種類**：画像／グラデ／単色
- **位置と大きさ**（画像のとき）：拡大縮小・左右・上下・回転・左右反転。キャンバスの何もないところをドラッグすると背景が動き、ホイールで拡大縮小できます
- **基準**：「全面」は隙間なく敷き詰め、「全体を表示」は画像全体が見えるように収めます（余った部分は「画像のぼかし」か「単色」で埋めます）

### 色調タブ（背景が画像のとき）

明るさ・コントラスト・彩度・色相・ぼかし・トーン（モノクロ／セピア／2色）。

### 効果タブ

- **ワンクリック背景エフェクト**：集中、集中線、疾走、ふんわり、文字を目立たせる、鮮やか、モノクロ、レトロ、デュオトーン、モノクロ＋赤、スポットライト、モザイク、リセット
- **エフェクト**（背景が画像のとき）：ズームブラー、モーションブラー、モザイク
- **背景エフェクト**：暗くする、周辺減光、グラデーション影（下を暗くして文字を読みやすく）、色を重ねる
- **中心 左右／上下**：周辺減光とズームブラーの中心。キャンバスの **黄色い◎** をドラッグしても動かせます（何も選んでいないときに出ます。上のガイドの「効果の中心」で表示の切り替え）

> ワンクリックの「集中線」「スポットライト」は、動的エフェクトのレイヤーを自動で作ります。あとから移動・調整でき、別のワンクリックに切り替えると入れ替わります。自分で追加した動的エフェクトはそのまま残ります。

## 5. 文字

キャンバスの文字をクリックすると、左に文字の設定が出ます。キャンバス上の文字をダブルクリック（スマホはダブルタップ）すると、すぐに「テキスト」タブで入力できます。

<p>
<img src="img/ins-text.png" width="260" alt="テキストタブ">
<img src="img/tab-style.png" width="260" alt="スタイルタブ">
<img src="img/tab-design.png" width="260" alt="装飾タブ">
</p>

### テキストタブ

- 改行するとそのまま複数行になります
- `{ }` で囲んだ部分は **強調色** になります（例：`今日は{神回}確定`）
- 太さ・サイズ・字間・行間・揃え
- 文字レイヤーは「＋追加」→「文字」でいくつでも置けます

### スタイルタブ

- **プリセット**：対戦格闘、メタル金、ネオン、炎、ホラーなど 40 種類以上。文字はそのままで見た目だけ変わります。カテゴリで絞り込めます
- **今の設定を保存**：自分で調整したスタイルをプリセットとして保存
- **初期化**：スタイルを最初の状態に戻します（文字はそのまま）
- **配色シャッフル**：色だけをランダムに変更。横のメニューで「補色」「類似色」「パステル」「ダーク・ネオン」などの方向性を選べます。「文字の塗り色は変えない」で塗り色を固定したままシャッフル
- **サムネおすすめ／カラーテーマ**：実績のある配色パターンをワンクリックで適用
- **全体の色調整**：色相・彩度・明るさをまとめて動かせます
- **背景画像から配色**：背景画像の色に合う配色を自動で作ります

### 装飾タブ

- **文字の塗り**：単色／グラデ／2色分割／金属
- **強調色**：`{ }` 部分の色
- **フチ**：何重にも重ねられます（内側→外側の順）
- **立体・影・光彩・ベベル・金属光沢**
- **変形**：ワープ変形、傾き・回転、ゆがみ、文字ゆらぎ
- **演出**：傍点、一文字囲み、背景シェイプ、模様、グリッチ、残像、炎、ドリップ、キラキラ、看板の電飾風、鏡面反射、床に映り込み

各セクションの右上のスイッチでオン／オフを切り替えられます。

### 配置タブ

大きさ・回転・不透明度・描画モード・ロック・9か所への整列。

#### 探す・選ぶ

- **検索・カテゴリ・用途**：「ゲーム・インパクト」「かわいい・ポップ」「和風・筆」など用途から探せます
- **英数字**：英字・数字だけ別のフォントにできます（例：「RANK UP」「No.1」）。一覧の欧文フォントにある「英数字」ボタンからも設定できます
- **お気に入り**：よく使うフォントを登録。お気に入りにした欧文は「英数字」の選択肢にも出ます

#### フォントを増やす

- **最新のフォント一覧に更新**：Google Fonts に新しく追加された日本語フォントを取り込みます。週に1回は自動でも確認します
- **WebフォントのURLを貼り付け**：次のURLに対応しています。追加したフォントは次回も一覧に残ります
  - Google Fonts のフォントのページ（`https://fonts.google.com/specimen/…`）
  - Google Fonts の CSS（`https://fonts.googleapis.com/css2?family=…`）
  - Fontsource のフォントのページ（`https://fontsource.org/fonts/…`）
  - `@font-face` を書いた CSS のURL
  - フォントファイルのURL（.woff2 / .woff / .ttf / .otf）。配布元が外部サイトからの利用を許可していない場合は読み込めません
- **PC にインストール済みのフォントを読む**（PC のみ）：Chrome / Edge ではインストール済みフォントをすべて読み込めます。初回は「フォントの使用」の許可を求められます。許可できない環境でも、よく使われるフォントは自動で見つけます
- **PC内のフォント名を入力して追加**：一覧に出てこないフォントも、名前を入れれば使えます（例：けいふぉんと）
- **フォントファイル**：.ttf / .otf / .woff / .woff2 をドロップ、またはクリックして選択

> ダウンロード配布だけのフリーフォント（けいふぉんと、にくまるフォントなど）は、PC にインストールしてから「PC にインストール済みのフォントを読む」か、フォントファイルをドロップしてください。

## 7. 画像

キャラクターの立ち絵、スタンプ、ロゴなどは **画像レイヤー** として重ねます。「＋追加」→「画像」か、画面へのドラッグ＆ドロップ・貼り付けで追加します。

<p>
<img src="img/ins-image.png" width="260" alt="配置タブ">
<img src="img/ins-frame.png" width="260" alt="フレームタブ">
<img src="img/ins-edge.png" width="260" alt="フチ・影タブ">
</p>

- **配置タブ**：大きさ・回転・**反転**・不透明度・描画モード・ロック・9か所への整列
  - **反転**：「左右」「上下」ボタンで画像を反転します（押すたびに切り替わり、反転中はボタンが黄色になります）。キーボードの `H`（左右）・`V`（上下）や、右クリックメニューからもできます。切り抜きフレームを付けているときは、フレームの位置や形はそのままで中の絵だけが反転します
- **フレームタブ**：図形で切り抜いて枠を付けます（→ [8章](#8-切り抜きフレーム)）
- **フチ・影タブ**：切り抜き画像（背景が透明な PNG）のまわりに白フチ、画像に影。「フチ太さ」は右の数字欄に 0.37 のように入力すると 0.01 単位で決められます（数字欄で ↑↓ キーでも 0.01 ずつ変わります）

## 8. 切り抜きフレーム

画像を図形で切り抜いて、枠を付けられます。画像を選んで「フレーム」タブを開きます。

### ワンクリック（40種類・5グループ）

**かわいい・ポップ**：アイコン、ポラロイド、ハート、吹き出し、マステ、スター、もこもこ、ステッカー、ワッペン、しずく、カプセル、なみなみ

![かわいい・ポップ](img/frames-pop.png)

**カッコいい**：サイバー、グリッチ、メタル、ゴールド、VS、ツインネオン、クリスタル、アロー、オーラ

![カッコいい](img/frames-cool.png)

**ゲーム・配信**：ワイプ、ファインダー、ゲーム風、バクハツ、ネオン、ゲーミング、8bit、レトロTV

![ゲーム・配信](img/frames-game.png)

**ブラシ・手作り感**：筆ひと塗り、かすれ筆、破れ紙、筆の四角、筆の三角、筆の丸、本、墨・筆

![ブラシ・手作り感](img/frames-brush.png)

**レトロ・アート**：アメコミ、フィルム、チケット

![レトロ・アート](img/frames-retro.png)

「フレームなし」で元に戻ります。

### 形と枠を自分で組み合わせる

- **形**（38種類）：四角（角丸）、丸、アーチ、六角形、八角形、ひし形、三角、平行四辺形、盾、星、キラッ、ハート、バクハツ、もこもこ、花、吹き出し、ラフな切り口、サイバーカット、HUD（角カット）、ブレード、台形、クリスタル、矢印、カプセル、スクワークル、五角形、縦六角形、十字、しずく、チケット、なみなみ、スプラッシュ、筆のひと塗り、かすれ筆、筆の四角、破れ紙、筆の三角、筆の丸
- **枠のデザイン**（26種類）：枠なし、単色のフチ、二重線、2色フチ（ポップ）、グラデーション、ネオン、2色ネオン、点線、ポラロイド風、マスキングテープ、サイバーHUD、ファインダー（四隅だけ）、グリッチ、メタル、立体影、ゲーミングRGB、オーラ（後光）、三重線、ステッカー、ステッチ（ワッペン）、アメコミドット、墨・筆、フィルム、ブラウン管、ドット絵、本（ページ）
- 枠の色と太さは「フチ色」「フチ太さ」、2色使うデザインは「2色目」で変えます
- **縦横比**：自動／1:1／4:3／3:4／16:9。自動は、四角やアーチなどは元の画像の比率、丸や星などは 1:1 になります
- **筆のかすれ**：筆・破れ紙・ラフな切り口などの形は「別パターンにする」で切り口の形を作り直せます
- 影（「フチ・影」タブ）を付けると、フレームの形に沿って影が付きます
- 枠の外側は透明です。内側は画像で埋まり、画像に透明な部分があれば透けます（ポラロイド風・本・フィルム・オーラは内側に下地を塗るので透けません）

### フレームの位置と大きさ

画像はそのままで、フレーム（切り抜く範囲）だけを動かしたり、大きさを変えたりできます。

![フレーム調整モード](img/frame-edit.png)

- **フレーム調整モード**：「キャンバスでフレームを調整」を押すか、フレーム付きの画像をダブルクリック（スマホはダブルタップ）すると入ります。画像全体が薄く表示されます
  - ドラッグ：フレームの位置を動かす
  - 角の ● をドラッグ・ホイール（スマホはピンチ）：フレームの大きさを変える
  - Esc・画像の外をクリック・「調整を終える」：モードを終了
- **スライダー**：「大きさ」「位置 左右／上下」でも同じ調整ができます
- 画像全体の大きさや位置を変えたいときは、ふだんどおりレイヤーをドラッグ・拡大縮小します

## 9. 分割フレーム（複数の画像を並べる）

2〜6枚の画像を、きれいに分割して並べられるレイヤーです。「＋追加」→「分割フレーム」で追加します。

![分割フレーム](img/collage.png)

### 分割タブ

- **分割数**：2〜6
- **分割のしかた**：縦に並べる／横に並べる／グリッド（4・6分割）／左に大きく／上に大きく／放射状（中心から扇形）。分割数に合わせて選べるものが変わります
- **傾き・回転**：境界を斜めにします（放射状は回転）。2分割＋斜めで「VS」風になります
- **大きいマスの大きさ**：「左に大きく」「上に大きく」のとき
- **境界の形**：まっすぐ／ギザギザ／波／ラフ（「形の大きさ」で調整）
- **境界線**：線／なし（ぴったり）／すき間（背景が見える）／光る線／ぼかしてつなげる／影で重ねる。「太さ・ぼかし」と「線の色」で調整
- **外枠・角の丸み**：全体のまわりにも線を付けたり、角を丸くしたりできます

### マスの画像タブ

![マスの画像タブ](img/ins-cells.png)

- **画像の入れ方**：マスに画像をドロップ（複数まとめてドロップすると順番に入ります）、または一覧でマスを選んで「画像を入れる」。画像のないマスをクリックすると、すぐにファイルを選べます
- **画像の大きさ・左右・上下**：選んでいるマスの中の画像を調整
- **マスの調整モード**：分割フレームをダブルクリックするか「キャンバスでマスの画像を調整」で入ります。マスをドラッグで中の画像を移動、ホイール（スマホはピンチ）で拡大縮小
- 画像を入れていないマスの「画像をドロップ」表示は、保存した画像には入りません

### 効果タブ

![効果タブ（左のマスは「モノクロ＋赤」、右のマスは「集中」）](img/collage-fx.png)

マスの画像に、背景と同じような色調やエフェクトをかけられます。

- **かける対象**：「全部のマス」はすべてのマスに同じ効果、「マスごと」は一覧で選んだマスだけに効果がかかります。「マスごと」に切り替えると、それまでの効果が各マスに写るので、そこから一部のマスだけ変えられます
- **ワンクリック効果**：鮮やか／ふんわり／モノクロ／レトロ／デュオトーン／モノクロ＋赤／暗く／集中／疾走／モザイク／なし
- **色調**：明るさ・コントラスト・彩度・色相・ぼかし・トーン（モノクロ／セピア／2色）
- **エフェクト**：ズームブラー（マスの中心へ吸い込まれる）・モーションブラー・モザイク・暗くする・周辺減光・色を重ねる
- **全体の影**：分割フレーム全体の下に影を付けます。背景の上に浮かせたいときに

### 配置タブ

大きさ・回転などに加えて、**横幅・高さ**と「画面いっぱいにする」があります。

## 10. 動的エフェクト

集中線・光・キラキラ・爆発は、**動的エフェクト** としてレイヤーで追加します。文字や画像と同じように移動・拡大縮小・回転でき、レイヤーパネルで重なり順を変えられます（キャラの後ろに集中線、など）。

![動的エフェクト](img/fx-layer.png)

1. 「＋追加」→「動的エフェクト」から種類を選びます
2. 今選んでいるレイヤーの **すぐ下** に追加されます。キャラを選んでから追加すると、キャラの後ろに入ります
3. ドラッグで移動、角の □ で拡大縮小、上の ○ で回転します
4. 「エフェクト」タブで細かく調整します

| 種類 | 調整できる項目 |
|---|---|
| 集中線 | 色、本数、内側の空き、線の太さ、長さのばらつき、ランダム、最大サイズ（「画面の端まで伸ばす」をオフにすると、外側の長さと外側のぼかしを指定できます） |
| 光（スポット） | 色、強さ、光の広がり（描画モードは初期値「スクリーン」） |
| キラキラ | 色、数、大きさ、光彩、ランダム |
| 爆発（ギザギザ） | 塗り色、フチ色、フチの太さ、トゲの数、トゲの深さ、ランダム |

背景全体にかける効果（ぼかし・周辺減光・モノクロなど）は、レイヤーではなく背景の設定の「効果」タブにあります（→ [4章](#4-背景)）。

## 11. レイヤーパネル

右のレイヤーパネルで、文字・画像・分割フレーム・動的エフェクトを管理します。

![レイヤーパネル](img/layers.png)

| 操作 | PC | スマホ |
|---|---|---|
| 選択 | 行をクリック | 行をタップ |
| 重なり順の入れ替え | 行をドラッグ（上にあるほど手前） | 左の ⋮⋮ をつまんで上下 |
| 表示／非表示 | 👁 | 👁 |
| ロック（キャンバス上で動かなくなる） | 🔒 | 🔒 |
| 不透明度 | 選んでいる行のスライダー | 選んでいる行のスライダー |
| 名前を変更 | ダブルクリック | メニューから |
| メニュー | 右クリック／… | 長押し／… |

- メニューには、最前面へ、前面へ、背面へ、最背面へ、複製、名前を変更、ロック、削除があります
- **背景** は一番下に固定です。行をクリックすると背景の設定が開きます。👁 と不透明度もあり、非表示にして PNG で保存すると背景が透明になります（JPG は透明にできないので白になります）

## 12. キャンバスの操作とガイド

| 操作（PC） | 内容 |
|---|---|
| クリック | 文字・画像・エフェクトを選択 |
| ドラッグ | 移動（中央・三分割線に吸い付く／Alt で無効） |
| 角の □ をドラッグ | 拡大縮小 |
| 上の ○ をドラッグ | 回転（Shift で 15° ずつ） |
| ホイール | 選択中のレイヤー、または背景を拡大縮小 |
| 何もない所をクリック | 選択解除（背景の設定へ） |
| 何もない所をドラッグ | 背景画像を移動 |
| ダブルクリック | 文字：入力／フレーム付き画像：フレーム調整／分割フレーム：マスの調整 |
| 右クリック | レイヤーメニュー |
| Alt＋クリック | 重なった下のレイヤーを選ぶ |
| 黄色い ◎ をドラッグ | 背景エフェクトの中心を移動 |

**ガイド**（キャンバス上部）

- **三分割**：構図の目安になる三分割線
- **再生時間**：YouTube の再生時間表示（右下）の位置。文字がかぶらないかの確認用。書き出しには入りません
- **スナップ**：中央・三分割線への吸い付きのオン／オフ
- **効果の中心**：背景エフェクトの中心 ◎ の表示

**情報バー**（キャンバス下部）

- **視認性**：文字の塗りと、そのすぐ外側（フチ・影・背景）の明るさの差です。◎ なら小さく表示されても読みやすい目安になります
- **小さく表示**：YouTube のおすすめ欄くらいの大きさで見え方を確認できます。押すとボタンが「大きく表示」に変わり、もう一度押すと元の大きさに戻ります

## 13. 保存・ファイルメニュー

- **サムネを保存**（右上）：画像ファイルとして書き出します。形式（PNG／JPG）とサイズ（1280×720〜4K）はヘッダーで選べます
- **コピー**：クリップボードにコピーします。Discord や X にそのまま貼り付けられます
- **ファイルメニュー**（ヘッダーのフォルダのアイコン）

![ファイルメニュー](img/file-menu.png)

- **プロジェクトを保存／開く**：画像も含めて .json に保存します。別の PC に持っていくときやバックアップに使えます
- **JPG を 2MB 以内に自動圧縮する**：YouTube のサムネ上限に収まるよう圧縮します
- **画面**：自動判定／PC／スマホ の切り替え
- **自動保存**：作業内容と読み込んだ画像は、ブラウザの中に自動で保存されます

> データはすべて使っている人のブラウザの中だけに保存されます。サーバーには送信されません。
> ブラウザのサイトデータを消すと作業内容も消えるので、大事なものは「プロジェクトを保存」しておいてください。

## 14. 文字素材モード（透過PNG）

ヘッダーの「**文字素材**」に切り替えると、文字だけを背景透過の PNG で書き出せます。動画編集ソフトや OBS のテロップ素材に使えます。

![文字素材モード](img/text-mode.png)

- 設定パネルは「テキスト／スタイル／フォント／装飾」の4つのタブです（サムネ作成と同じ使い方）
- **倍率**（ヘッダー）：1x〜4x（大きいほど高解像度）
- **背景**：透過／黒／グレー／白／画像。プレビューの確認用で、書き出しは透過になります
- **余白**：文字のまわりの余白

## 17. こまったときは

| こまりごと | 対処 |
|---|---|
| 設定したい項目が見つからない | まず設定したいもの（文字・画像など）を選び、左の設定パネルのタブを見てください。背景の設定は、何も選んでいないときに出ます |
| 文字が小さく読みにくい | 下の「視認性」が ◎ になる配色にする。「小さく表示」でスマホでの見え方を確認 |
| 失敗した | `Ctrl+Z` か上の ↶ で戻せます |
| 文字のスタイルを最初からやり直したい | 文字を選んで「スタイル」タブの「初期化」（文字はそのまま残ります） |
| PC のフォントが一覧に出ない | 「フォント」タブの「PC にインストール済みのフォントを読む」を押す。それでも出ない場合は「PC内のフォント名を入力して追加」 |
| 文字や画像がつかめない | レイヤーがロックされていないか確認（🔒）。重なっている場合は Alt＋クリックかレイヤーパネルから選ぶ |
| 集中線がキャラにかぶる | レイヤーパネルで集中線をキャラより下にドラッグ |
| ページを開くと翻訳するか聞かれる | 日本語ページとして設定しているので通常は出ません。出た場合は「翻訳しない」を選んでください |
| 作ったものが消えた | 別のブラウザ・シークレットウィンドウでは保存内容が共有されません。いつものブラウザで開いてください |
