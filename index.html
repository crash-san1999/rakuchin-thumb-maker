フォント

英字・数字だけ別のフォントにできます（例：「RANK UP」「No.1」「1000」）。

フォントを増やす
タップしてフォントファイル（.ttf / .otf）を選ぶフォントファイル（.ttf / .otf / .woff / .woff2）をドロップ、またはクリックで選択

PC内フォントは、Chrome / Edge でファイルを直接開くと全件読み込めます（初回に「フォントの使用」の許可が出ます）。許可できない環境でも、よく使われるフォントは自動で検出します。確実なのはフォントファイルのドロップです。
Google Fonts の日本語フォントは最初から全書体使えます（キー不要）。WebフォントのURLは、Google Fonts のページURL（fonts.google.com/specimen/…）、Fontsource のページURL（fontsource.org/fonts/…）、@font-face を書いたCSS、フォントファイル（.woff2 など）に対応しています。
Webフリーのフォントはそれぞれのライセンス（主に SIL OFL）で配布されています。

設定パネルのしくみ

選んだもの（文字・画像・分割フレーム・エフェクト）に合わせて、左の「設定」のパネルがそのための設定に切り替わります。何も選んでいないときは背景の設定です。追加はすべて「＋追加」から。

1
背景を決める

何も選んでいない状態で左の下の「背景」の「背景」タブから画像・グラデ・単色を選択。画像はドラッグで移動、ホイール2本指ピンチで拡大縮小。「効果」タブでズームブラーやワンクリック背景エフェクト。

2
文字を入れる

文字を選ぶと「テキスト」「スタイル」「フォント」「装飾」「配置」のタブが出ます。{ } で囲むと強調色に。「スタイル」でプリセットと配色を選ぶだけで完成します。

3
画像を重ねる

画像ファイルを画面にドラッグ＆ドロップ（またはコピーして Ctrl+V）、または「＋追加」→「画像」でレイヤーとして追加。「フレーム」タブで切り抜き、「フチ・影」タブで白フチや影。複数の画像を並べるなら「分割フレーム」。

4
保存する

右上の「保存」でPNG／JPGを書き出し。共有メニューの「画像を保存」で写真アプリに入ります。プロジェクトの保存・開くは上のフォルダのアイコン（ファイル）から。作業内容はブラウザに自動保存されます。

レイヤー

集中線・光・キラキラ・爆発は「動的エフェクト」としてレイヤーで追加（「＋追加」から）。文字や画像と同じく移動・拡大・回転でき、キャラの後ろに集中線…のように重なり順で調整できます。ぼかし・モノクロ・周辺減光などは背景の設定で。
右の（下の「レイヤー」の）パネルで、上にあるほど手前。行をドラッグ⋮⋮ をつまんで上下で重なり順を入れ替え。👁で表示切替、🔒でロック（キャンバス上で動かなくなる）。ダブルクリックで名前変更。
